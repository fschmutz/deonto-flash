# Code de conduite

Ce projet applique le [Contributor Covenant 2.1](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/).

En résumé : soyez courtois et précis. Les désaccords sur le fond du droit sont bienvenus
et se tranchent par le texte applicable, jamais par le ton.

Tout comportement inapproprié peut être signalé en ouvrant une issue privée auprès du
mainteneur du dépôt.
